# Կայքի պատվերներ. հիշեցում աշխատակիցների համար

Տպեք և փակցրեք վաճառասեղանի մոտ։

## Երբ Telegram-ով նոր պատվեր է գալիս

1. **Բացեք պատվերը** կառավարման վահանակում (`/admin` → Պատվերներ)։
2. **Զանգեք հաճախորդին** մինչև պատրաստելը։ Վճարումը տեղում է. զանգը հաստատում է պատվերը։
3. Սեղմեք **Հաստատեց հեռախոսով** կամ **Չպատասխանեց**։
4. Պատրաստելիս փոխեք կարգավիճակը.
   **Հաստատված → Պատրաստվում է → Ճանապարհին է (առաքում) → Ավարտված**։
5. Հաճախորդը կարգավիճակը տեսնում է իր հղումով. պահեք այն թարմ։

## Եթե…

| Իրավիճակ                            | Ինչ անել                                                         |
| ----------------------------------- | ---------------------------------------------------------------- |
| Ապրանքը վերջացել է                  | Ապրանքներ և արժեքներ → հանեք **առկա է** → Պահպանել               |
| Հաճախորդը չի պատասխանում            | **Չպատասխանեց**, 10–15 րոպե հետո կրկին զանգեք                    |
| Պատվերը կեղծ է                      | **Կեղծ պատվեր է, չեղարկել**, ապա **Արգելափակել համարը**          |
| Հաճախորդը փոխում է պատվերը          | Գրեք **Ներքին նշում** դաշտում                                    |
| Միջոցառման կամ գրասենյակի հայտ      | Հաղորդագրություններ → զանգեք, պատասխանեք, **Նշել որպես մշակված** |
| Այսօր չենք կարող ընդունել պատվերներ | Ադմինիստրատորին խնդրեք Կարգավորումներում անջատել պատվերները      |

## Կարևոր

- Մի տվեք ձեր գաղտնաբառը ուրիշին. յուրաքանչյուրն ունի իր մուտքը։
- Հաճախորդների հեռախոսները և հասցեները օգտագործեք միայն պատվերի համար։
