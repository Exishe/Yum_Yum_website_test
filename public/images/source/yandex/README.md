# Фото заведений

43 отобранных фото из галерей Яндекс.Карт (6 филиалов), скачано 21.10.2026.
Размер до 1280 px. Это в основном фото посетителей.

- `storefront/`: фасады и вывески
- `interior/`: интерьер, стойки с неоновым логотипом
- `showcase/`: витрины с донатами (подходят для баннера)
- `products/`: товары и напитки в руках
- `menu-boards/`: меню напитков на стенах

Права принадлежат авторам фото. Для демо подходят, для публичного запуска
нужны собственные фото Yum-Yum.
